# Attar Homebrew tap

Homebrew distribution for Attar on Apple Silicon with macOS 15 or newer.

Requires Xcode Command Line Tools. Install Attar from this tap:

```sh
brew tap occam-tech/attar
brew install occam-tech/attar/attar
```

The published formula installs the current macOS developer archive. Mac
installation, starter build, and GUI runtime verification remain pending.

[Attar developer packages](https://github.com/occam-tech/attar-releases)
